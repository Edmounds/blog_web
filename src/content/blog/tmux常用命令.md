### 1. 创建新会话

创建默认名称的新会话：

```
tmux
```

创建指定名称的新会话：

```
tmux new -s <会话名>
```

### 2. 离开会话

在 tmux 窗口内按下快捷键。
1. 按下 `Ctrl + b`
2. 松开按键后按下 `d`。

终端将退出 tmux 界面。 后台程序会保持运行状态。

### 3. 查看后台会话

列出所有处于运行状态的会话：

```
tmux ls
```

### 4. 恢复已有的会话

恢复最近使用的一个会话：

```
tmux a
```

恢复指定名称的会话：

```
tmux a -t <会话名>
```

### 5. 关闭与销毁会话

在外部终端销毁指定的会话：

```
tmux kill-session -t <会话名>
```

销毁所有的 tmux 会话：
```
tmux kill-server
```
