# 我對東野圭吾的印象
我第一次閱讀東野圭吾的作品，應該是他的《解憂雜貨店》

我記得當時是小學，我當時暑假在表姐家玩，那會沒有手機玩就，於是只能看​​書了，剛好有一本解憂雜貨店，單從標題看我以為是日常休閒類型的書呢，這本書挺精彩的，通過跨越時空的信件實現的救贖，也讓我記下了這個作者。
下一次再相見就是高二了。

當時我們宿舍開始傳閱《白夜行》，我記得至少有三個人是用那個kindle看完的《白夜行》。當時真的是廢寢忘食，跟追《絕命毒師》有的一比，btw我追網路小說都沒追這個那麼積極。輪換到我看的時候，我基本上就是自習課抓緊寫完作業就開始偷偷看、邊吃飯邊看、寢室熄燈了也繼續看(感謝這款背光的kindle).我是第一次看這種尺度有點大的懸疑小說，雖然黑暗但是又有一種真實感，而且男女雙視角的主線也很難挺的，更令人困擾的劇情是蠻宕起伏。讓人最意難平的是，桐原亮司最後透過自殺保護了雪穗，雪穗居然能面無表情說出「我完全不認識這個人」。

後面再見到「雪穗」就是在《幻夜》中了，這個故事寫的沒有《白夜行》精彩，也差強人意吧。 《幻夜》的結局也和《白夜行》很像，男主角最後知道了女主角一直在欺騙和利用自己， 但最後他還是為了保護女主角而自殺，讓女主角清白脫身。

R.I.P.
