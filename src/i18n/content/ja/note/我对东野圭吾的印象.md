# 東野圭吾に対する私の印象
	私が初めて東野圭吾の作品を読んだのは、たぶん彼の『ナミヤ雑貨店の奇蹟』だった。
	当時は小学生で、夏休みに従姉の家で遊んでいた。あの頃は携帯電話もなかったので、仕方なく本を読むことになったのだが、ちょうど『ナミヤ雑貨店の奇蹟』が一冊あった。タイトルだけを見て、日常的で気軽に読めるタイプの本だと思っていた。この本はとても面白く、時空を超えた手紙によって救済が実現されていく物語に惹かれ、私もこの作家の名前を覚えることになった。
	次に再会したのは高校2年生の頃だった。
	その頃、私たちの寮では『白夜行』を回し読みし始めた。少なくとも3人は、あのKindleで『白夜行』を読み終えたのを覚えている。本当に寝食を忘れて夢中になり、『ブレイキング・バッド』を追いかけていた時と比べても引けを取らなかった。ちなみに、ネット小説を読む時でさえ、これほど積極的に追いかけたことはなかった。私の番に回ってきた時は、基本的に自習の時間に急いで宿題を終わらせてからこっそり読み始め、食事をしながら読み、寮の消灯後も読み続けていた（このバックライト付きKindleに感謝）。こういう少し刺激の強いミステリー小説を読むのは初めてだった。
