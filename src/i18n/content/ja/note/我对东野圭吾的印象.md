# 東野圭吾についての印象
私が初めて東野圭吾の作品を読んだのは、おそらく彼の『ナミヤ雑貨店の奇蹟』だった。

当時は小学生で、夏休みに従姉の家で遊んでいた。あの頃は遊べる携帯電話もなかったので、仕方なく本を読むしかなかった。ちょうど『ナミヤ雑貨店の奇蹟』が一冊あり、タイトルだけを見て、日常系の気軽な本だと思っていた。この本はとても面白く、時空を越えた手紙によって救いがもたらされる物語に、私はこの作家のことを覚えておくようになった。

次に再会したのは、高校2年生の頃だった。

当時、私たちの寮では『白夜行』を回し読みし始めた。少なくとも3人は、あのKindleで『白夜行』を読み終えたのを覚えている。本当に寝食を忘れて夢中になり、『ブレイキング・バッド』を追いかけていた時と比べても遜色なかった。ちなみに、ネット小説を読む時でさえ、これほど熱心に追いかけたことはなかった。自分の番が回ってきてからは、基本的に自習の時間に急いで宿題を終わらせてこっそり読み始め、食事をしながら読み、寮の消灯後も読み続けていた（バックライト付きのこのKindleには感謝している）。

このように少し刺激の強いミステリー小説を読んだのは初めてだった。暗い作品ではあるものの、どこか現実味があり、男女それぞれの視点で進んでいく主軸もかなり面白かった。何より、展開が本当に波瀾万丈で、犯人を当てるのは難しかった。最もやりきれなかったのは、桐原亮司が最後に自殺することで雪穂を守ったのに、雪穂が平然と「私はこの人をまったく知りません」と言い放ったことだ。

その後、再び「雪穂」に出会ったのは、『幻夜』だった。この物語は『白夜行』ほど面白くはなく、まあ悪くはないという程度だった。『幻夜』の結末も『白夜行』とよく似ている。主人公の男は最後に、ヒロインがずっと自分をだまし、利用していたことを知る。それでも最後には、ヒロインを守るために自殺し、彼女を無傷で逃がす。

その他の本についてはいちいち詳しく述べない。下の画像は、私が読んだ東野圭吾の作品だ。

![image.png](https://img.muelsyse.us/bed/20260808043442545.png)

東野圭吾は偉大な作家だ。本を読む習慣のなかった私でも、一冊の本を最後まで集中して読み通せるようにしてくれたことに感謝している。そして、彼が生み出した、いつまでも心に残る物語にも感謝したい。
R.I.P.
