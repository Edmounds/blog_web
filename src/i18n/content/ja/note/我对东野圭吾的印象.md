# 東野圭吾に対する私の印象
私が初めて読んだ東野圭吾の作品は、たしか『ナミヤ雑貨店の奇蹟』だった。

当時は小学生で、夏休みにいとこの家で遊んでいた。あの頃はスマホもなかったので、仕方なく本を読むことにした。ちょうど『ナミヤ雑貨店の奇蹟』が一冊あり、タイトルだけを見て、日常系の気軽な本だと思っていた。この本はとても面白く、時空を超えた手紙によって描かれる救いに心を動かされ、この作家の名前を覚えるきっかけにもなった。
次に再会したのは高校2年生のときだった。

当時、私たちの寮では『白夜行』を回し読みし始めた。少なくとも3人は、あのKindleで『白夜行』を読み終えたのを覚えている。本当に寝食を忘れて夢中になり、『ブレイキング・バッド』を追いかけていたときと比べても引けを取らなかった。ちなみに、ネット小説を読むときでさえ、これほど熱心に追ったことはなかった。私の番が回ってきたときは、自習の時間に急いで宿題を終わらせてからこっそり読み始め、食事をしながら読み、寮の消灯後も読み続けた（このバックライト付きKindleには感謝している）。このようにスケールの大きいミステリー小説を読むのは初めてだった。暗い作品ではあるものの、どこか現実感があり、男女それぞれの視点から進んでいく物語もなかなか面白かった。何より、展開が本当に波乱に富んでいて、犯人を当てるのが難しかった。最もやりきれなかったのは、桐原亮司が最後に自殺することで雪穂を守ったのに、雪穂が平然と「私はこの人をまったく知りません」と言い放ててしまったことだ。

その後、再び「雪穂」と出会ったのは『幻夜』だった。この物語は『白夜行』ほど面白くはなく、まあまあ、といったところだった。『幻夜』の結末も『白夜行』とよく似ている。主人公の男性は最後に、ヒロインがずっと自分をだまし、利用していたことを知る。それでも最後には、彼女を守るために自殺し、彼女を無傷で逃がす。

ほかの作品については一つひとつ詳しく述べない。下の画像は、私が読んだ東野圭吾の作品だ。
![読んだ東野圭吾の作品|475](https://img.muelsyse.us/bed/20260808043442545.png)


東野圭吾は偉大な作家だ。本を読む習慣のなかった私でも、一冊の本を最後まで集中して読めるようにしてくれたこと、そして、いつまでも余韻の残る物語を生み出してくれたことに感謝している。

R.I.P.
