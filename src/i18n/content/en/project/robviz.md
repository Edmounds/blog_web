## Project Overview

robviz is a lightweight ROS2-based 2D robot pose and map visualization tool designed to provide a real-time debugging view with extremely low resource usage.

## Features

- Minimal dependencies; relies only on the core ROS2 libraries
- Real-time subscription to the `/map` and `/tf` coordinate frames
- Support for custom robot outlines and LiDAR point-cloud layers
