## Project Overview

robviz is a lightweight ROS2-based tool for visualizing 2D robot poses and maps, designed to provide a real-time debugging view with minimal resource usage.

## Features

- Minimal dependencies; relies only on core ROS2 libraries
- Real-time subscriptions to the `/map` topic and `/tf` coordinate frames
- Supports custom robot outlines and LiDAR point cloud layers
