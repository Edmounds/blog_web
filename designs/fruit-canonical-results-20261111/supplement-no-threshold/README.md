# 专用评测集：逐目标最高分补充评测

用户于2026-11-11确认，专用评测集就是`canonical_rebuild_20261111/data/external`中的60张图片、91个标注目标。本轮全部统计使用这套评测集。

取消0.25分数过滤后，复合标签与两阶段方案都完整识别66/91个目标，均为72.53%。这项补充结果不支持此前固定阈值下的两阶段优势继续成立。

## 评测集与模型来源

已重新核对15437个数据文件。专用评测集与2460张训练图、250张验证图、116张内部测试图的原图组、图片SHA256和解码像素哈希重合均为0。检测器实际图片目录与清单一致，成熟度切片全部来自内部划分。完整训练包哈希与原记录一致，未包含专用评测图片。检查范围是本轮10个重新训练的模型。

本地10个ONNX模型的SHA256与lab当前文件、训练记录全部一致。四个用于提取类别分数的PT权重也与本轮训练记录一致。没有换用早期模型。

证据见`dedicated-set-isolation.json`和`model-source-verification.json`。

## 逐目标统计

保留导出的每图最多300条候选，取消分数下限。同一原始空间候选只保留最高分类分数。按模型分数降序，与全部标注目标执行一对一匹配，IoU仍须达到0.50。类别正确与否不参与匹配，分类器仍按预测类型路由。

| --- | ---: | ---: |
| 标注目标 | 91 | 91 |
| 有位置合格的匹配结果 | 87 | 90 |
| 类型正确 | 71 | 68 |
| 类型和成熟度均正确 | 66 | 66 |

双方都正确55个，仅复合标签正确11个，仅两阶段正确11个，双方均未正确14个。相同总数不代表错误目标相同。

取消分数过滤会保留大量背景和重复候选。按空间候选去除同框重复类别后，双方分别保留11271和14405个候选，其中11184和14315个未匹配标注。这些候选均保留在原始预测分母中。表中的72.53%是以91个目标为分母的完整识别比例，不能据此声称全图自动输出已达到可用精确率。

## 与原固定阈值结果的关系

原有0.25阈值、IoU优先匹配结果保持39/91和46/91，独立重放全部计数一致。

统一使用本次“最高分优先”匹配方式后，0.25阈值下为40/91和46/91，取消过滤后双方均为66/91。复合标签在0.25下多出的1个正确目标来自匹配顺序变化。该控制比较保存在`margin-analysis.json`的`confidence_controlled_comparison`中。

原先44个复合标签漏检中，40个有低于0.25的合格位置候选，4个没有达到IoU0.50的导出框。两阶段对应37个漏检中，36个有低分合格候选，1个没有合格框。

另保留只取消过滤、继续IoU优先匹配的诊断结果。取消过滤后，这种匹配可能优先选择定位略好但分数很低的候选。主表按用户要求采用最高分优先。

## 同一目标的第一、第二类别

检查了两种竞争：同一候选框内部的类别分数，以及同一目标周围不同候选框的类别分数。后一种检查对每个标注目标收集合格框，分别取每个类别的最高分。标注类别不参与选分。

复合标签比较类型时，取同类型两种成熟状态分数的最大值。这保持原模型的类型选择。另保留完整复合标签之间的竞争，避免把成熟状态切换漏掉。

使用相对分差`(s1-s2)/(s1+s2)`描述接近程度。小于0.10等价于第一名不足第二名约1.22倍。该界限仅用于补充诊断，并未经过视频稳定性校准。

| 同目标竞争指标 | 复合标签 | 两阶段类型检测 |
| --- | ---: | ---: |
| 有合格框的目标数 | 87 | 90 |
| 类型第一、第二名相对分差中位数 | 0.9955 | 0.9962 |
| 类型分数接近的目标 | 1/87 | 2/90 |
| 原生标签分数接近的目标 | 2/87 | 2/90 |

复合标签有1个额外的成熟/未成熟竞争案例，来自同一苹果的不同候选框。同框内部比较没有发现这个案例。两阶段最后一行仅指类型检测标签，成熟度分类需单独检查。

类型正确目标上，复合标签71个目标和两阶段68个目标的选中框内，都没有相对成熟度分差小于0.10的案例。但双方仍分别有5个和2个成熟度错误，分差大不能保证正确。

具体例子：

- `20260823_030002_475`第2个目标，复合标签的苹果分数约0.003442，梨约0.003081，存在接近竞争。
- `IMG_20260916_023238`第4个目标，两阶段把洋葱识别为番茄，番茄约0.0003371，辣椒约0.0003277。第一、第二名都没有给出正确类型。
- `20260823_025605_310`第2个目标，不同候选框给出的未成熟苹果约0.000002972，成熟苹果约0.000002684。这种竞争值得在视频中继续检查。

也存在明显高分认错。两阶段有苹果被识别成梨，梨约0.965，苹果约0.0000962。这说明本组错误并非普遍由第一、第二名接近造成。

这些数据来自静态图片。尚未测量相邻帧换类率、目标跟踪中断或视频推理时延。换框、遮挡和视角变化仍可能改变类别，不能把静态大分差直接写成视频稳定。
